# agentinfra

English | [简体中文](README.zh-CN.md)

Single-machine agent infrastructure: Infra, Gateway and Harness are separate layers, so many agents can push one project forward at the same time.
The design is described in the implementation document *Agent Infrastructure 单机版实现文档*.

| Layer | Directory | Language | Processes |
| --- | --- | --- | --- |
| Infra: workspaces, versions, execution, work items, merge queue | `infra/` | Rust | `infrad`, `infra-sandboxd`, `infractl` |
| Harness: agent loop, four built-in tools | `harness/` | TypeScript (Node ≥ 22.18) | `harnessd`, `agentctl` |
| Gateway: model routing, budgets, context protection and compression | `gateway/` | Python ≥ 3.12 | `gatewayd` |

The layers talk only through MCP (Infra, `127.0.0.1:7070/mcp`) and the model API (Gateway); they never import each other's code.
`schemas/` is the single source of the interface; types for all three languages are generated by `tools/schema/codegen.py`.

## Layout

```
infra/crates/      Rust crates; the ones absorbed from LayerFS are listed in UPSTREAM.layerfs.toml
infra/bin/         infrad, infra-sandboxd, infractl
harness/           core, seams, server, tools, agentctl (pnpm workspace)
gateway/           gatewayd (uv project)
schemas/           common/ (envelope, error codes) and tools/<group>/<tool>.json
migrations/        PostgreSQL migrations, including the atomic-operation functions
instructions/      Infra usage rules sent to agents
prompts/           coordinator and worker prompts
tools/             schema validation and codegen, upstream absorption, migration tests
third_party/       third-party licenses and NOTICES
deploy/systemd/    single-machine units
tests/             e2e, storage, fault, security, conformance-pi
```

## Common commands

The root `justfile` is the single entry point:

```sh
just check           # schema validity, generated-code freshness, cargo check, tsc, Python compile check
just test            # unit tests in every language + migration tests (needs a local PostgreSQL 16)
just codegen         # regenerate the bindings for all three languages from schemas/
just absorb-layerfs  # re-run the absorption from the upstream/layerfs branch per UPSTREAM.layerfs.toml
```

## Upstream

Reference projects are sources, not dependencies. Each upstream has a read-only mirror branch `upstream/<project>` that is never merged into `main`.
The absorption mapping, our changes and the upstream changes we declined are recorded in `infra/UPSTREAM.<project>.toml`.
